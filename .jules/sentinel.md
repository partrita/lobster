## 2026-03-28 - [CRITICAL] Fix command injection in dataset indexing
**Vulnerability:** Command Injection (CWE-78) in `src/lobster/datasets/_fasta_dataset.py` and `src/lobster/data/_structure_datamodule.py`. The `_build_index` methods invoked `subprocess.check_output` with `shell=True` and string interpolation, directly passing user-supplied `root` or `data_file` paths. A malicious path string could lead to arbitrary code execution.
**Learning:** Using `shlex.quote` to escape string parameters for shell interpolation does not completely remove security scanner flags (like Bandit) and can sometimes still be fragile or flagged in CI (e.g. Sourcery). It is better to avoid `shell=True` entirely and use a pipeline of `subprocess.Popen` commands passing explicit string arrays instead.
**Prevention:** Avoid `shell=True` in Python subprocess calls. When shell pipes are needed, construct explicit pipes by passing `stdout=subprocess.PIPE` from one `Popen` instance to `stdin` of the next.
